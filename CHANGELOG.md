# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-02-15

### Added
- Initial release
- Autodarts Desktop installer and updater
- Service management (start, stop, restart, enable, disable)
- UVC hack install/uninstall support
- Configuration module with dataclass
- Makefile for convenience commands
- CLI interface with argparse
- Python module API for integration
- Deployment guide and documentation
- Quick reference guide
- Usage examples
- Upload script for Raspberry Pi deployment
